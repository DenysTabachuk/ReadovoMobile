# Topic cover illustrations

Original AI-generated decorative catalogue artwork, created on 2026-11-18 with
the built-in image generation tool. These covers do not replace word-card images
or imply approval of the sample as production lesson content.

- `everyday-life.png`: cover for the local Everyday Life sample, served for the
  object key `learning/topics/everyday-life/v1.png`.
- `discover-topics.png`: neutral cover for absent/unresolved topic image keys.
- `germany.png`: Germany/Oktoberfest test-topic cover, for the object key
  `learning/topics/germany/v1.png`.

The API owns the topic's optional cover key. Lesson cards inherit their topic's
cover. Bundled resolution is local to the learning feature; remote media delivery
can be introduced separately without inventing public URLs in the database.
