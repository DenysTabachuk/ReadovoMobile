# TODO: стабільні коди помилок mascot API

Статус: заплановано. Використати спільний формат відповіді з кодами помилок для streak і mascot.

## Проблема

`resolveMascotErrorMessage` розпізнає помилки за точним англійським текстом `message`.
Зміна формулювання або пунктуації на бекенді призводить до стандартного повідомлення
замість відповідного перекладу.

## Запропонований контракт

```json
{
  "statusCode": 400,
  "code": "MASCOT_NOT_ENOUGH_COINS",
  "message": "Not enough coins."
}
```

`code` — стабільний ідентифікатор для клієнта. `message` залишається поясненням для
діагностики й не використовується для вибору перекладу. `statusCode` має відповідати
HTTP-статусу; міграція не повинна сама по собі змінювати поточні статуси.

| Поточний текст              | Запропонований код        | Ключ перекладу                 |
| --------------------------- | ------------------------- | ------------------------------ |
| `Not enough coins.`         | `MASCOT_NOT_ENOUGH_COINS` | `mascot.errors.notEnoughCoins` |
| `Mascot item is not owned.` | `MASCOT_ITEM_NOT_OWNED`   | `mascot.errors.itemNotOwned`   |

Це запропоновані коди, які ще потрібно погодити та реалізувати.
